# 设计决策

- 使用 Go + mygo 原生界面。采集通过 purego 直调 macOS 原语，无需另写原生桥。时间轴与设置使用 Go 控件，省去 WebView 和 Node/Bun 前端工具链。ui.NewTester 支持无窗口界面测试。平台原语留在采集后端，避免系统权限与图像生命周期渗入界面。
- 纯状态机只决定动作，Runner 执行动作。系统观测、平台能力和时钟可替换，让时间与并发边界能用假依赖验证。平台适配存在不代表全功能已实现。
- OCR 使用原分辨率帧，持久化 JPEG 独立缩放和压缩。识别不依赖磁盘缩略图，存储降质不降低已入队帧的识别质量。有界识别队列和去重限制积压及重复证据。
- JSONL 按天追加，JPEG 通过路径引用。日期分区支持逐日读取与保留清理，无需重写整个历史文件。当前格式继续使用；本决策不预设数据库迁移路线。
- 界面跨帧保存数据、控件状态与 Handle。Element 只属于当前构建。后台结果通过 Window.Update 发布，避免后台任务持有构建值或直接修改界面状态。
- 记录器总开关控制采集生命周期。会话保存结束原因，保留天数与磁盘配额约束历史数据，旧截图分层降质。
- 脱敏总开关同时控制摘要请求与 query 文字。开启时按规则遮蔽，关闭时保留原文。截图不脱敏；Agent 的后续传输由其自身决定。
- Agent 使用无密钥、无写入路径的 query 按需读取。入口在窗口创建前分流，不启动记录器、模型服务或 CLI 凭据扫描，查询缺失目录也不创建它。
- 技能只安装说明，记录留在数据目录。应用停止生成静态技能数据，避免安装位置与记录同步耦合。旧导出通过固定内容标记识别删除，新技能和用户文件保留。
- e2e 的许可检查位于实际 Screen 和公开授权入口。环境值必须严格等于 1，避免界面开关意外开启真实采集。live 默认写入 0 并清除继承许可；正式构建忽略此变量。测试放行通过假后端验证，不借用真实权限。
- 小票呈现摘要；简体中文与英文共享类型化消息目录。
- 应用图标画小票从出纸口吐出，色值取自小票界面。机身不加指示灯：静止的绿点像摄像头灯，暗色灯珠像镜头开孔。纸上印时刻，不印金额，避免读成记账应用。单条轨迹类方案在 32 像素下读成 S、$、5 或「己」，已否决。外形用连续曲率圆角，参数 214，与 macOS 27 系统蒙版吻合。
- 开发版图标只把机身换成琥珀色，琥珀取自暂停指示灯。系统六种图标风格下，琥珀机身都比炭黑机身亮，Dock 里一眼分开。黄纸加横线像「备忘录」，印章在 32 像素下看不见，均已否决。
- 不用 Icon Composer 分层图标（.icon）。macOS 27 六种图标风格下，系统画出的分层版与现行 PNG 几乎一致。分层版要在仓库里放 1.6 MB 的 Assets.car 和第二份母版，macOS 13 到 15 还会改用 actool 生成的扁平图。系统开始给 PNG 图标套灰底，或六种风格出现明显差异时，再做分层版。
