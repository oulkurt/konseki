# 设计决策

- 平台能力收敛到 capture 接口，状态机与存储共用。平台适配不构成全功能承诺。
- JSONL 与 JPEG 保持当前落盘格式。此决策不要求未来迁移到特定数据库。
- 抓帧和 OCR 分离。有界识别队列限制积压，去重减少重复证据。
- 总开关控制记录生命周期；会话保留结束原因。磁盘配额与保留天数约束记录，截图分层降质。
- 模型摘要使用脱敏文字。截图保留可读图像，不宣称图像脱敏。
- Agent 使用只读 query 按需读取。技能安装与记录存储分离。其他 Agent 的外传行为不由 Konseki 保证。
- e2e 默认禁止真实采集与权限请求，显式环境授权后才放行。自动化启动器默认不授权。
- 小票呈现摘要；简体中文与英文共享类型化消息目录。
