# 设计决策

- 使用 Go + mygo 原生界面。采集通过 purego 直调 macOS 原语，无需另写原生桥。时间轴与设置使用 Go 控件，省去 WebView 和 Node/Bun 前端工具链。ui.NewTester 支持无窗口界面测试。平台原语留在采集后端，避免系统权限与图像生命周期渗入界面。
- 纯状态机只决定动作，Runner 执行动作。Machine 与 Runner 共用 EffectivePhase 与显式作业槽（jobKind）和结果枚举（captureOutcome），消灭状态撕裂和优先级反转。系统观测、平台能力和时钟可替换，让时间与并发边界能用假依赖验证。平台适配存在不代表全功能已实现。
- 界面后台任务（摘要、清空、测试连接、模型拉取、凭据扫描、自动摘要循环）全部由 appTasks 结构化并发作用域管理，退出时先取消并等完后台任务，再以 Runner.Close 等待采集维护退出，而日常暂停/关闭开关调用的 Runner.Stop 仅等待采集循环退出（含当次抓帧收尾与有界关闭 OCR 队列）并跳过后台维护任务的等待。
- 界面错误拆分为配置写入错误（app.err）、常规读取错误（app.readErr）、供应商/摘要失败错误（summary.err）和摘要读取错误（summaryReadErr），互不覆写，时间轴渲染对应日期或全局配置错误；清空成功后经 rebuildGenerator 重新校验供应商配置，保留未修复的配置错误。清空按钮在存在残余失败或旧导出文件时保持可重试。小票送纸、新条目展开与碎纸动画采用显式阶段枚举和两阶段测量，离开碎纸态必须经统一 stop 清零物理与探针状态，切换标签页时清零滚动位置并清除输入草稿聚焦态，避免组件卸载引发僵尸提交。
- 供应商在创建与写入时分配不可复用的随机持久 ID（NewProviderID）作为编辑、新增定位、删除匹配、选型、密钥隔离与行容器 c.Key 的单一真相源（旧配置无 ID 的磁盘读取保留确定性兼容归一化）；默认供应商先全局按 ID 精确解析，仅在无 ID 命中时回退到一个旧预设条目，修改 Key、地址或默认供应商同步重建摘要生成器，并在供应商设置行按协议拉取模型列表（Anthropic 协议请求 /v1/models）。
- 持久化边界实行跨实例目录锁、事务提交、代次隔离与版本写保护：config.Store 在 Load 与 Update 内持有目录级 OS 锁（Unix flock / Windows LockFileEx），在重放 .config.tx.json 前先校验磁盘与事务版本防降级，在锁内重读磁盘状态并复核版本号后以独立 0600 .secrets.tx 保存事务密钥、.config.tx.json 仅存配置与 secretsSha256（兼容旧内联事务恢复）配合两阶段提交+回滚保护双文件一致性，清理阶段先删 .config.tx.json 并确认成功后再清理 .secrets.tx 防止中断留下失效校验引用；Read 与 txConfigVersion 通过固定 4 KiB 读缓冲区的逐字节扫描提取器只读未提交事务的 config 字段（既不打开 .secrets.tx 也不打开 secrets.json，跳过含大体积与 `\uXXXX` 转义串在内的旧事务 secrets 字段时零堆分配、不保留且不做 Base64 解码）；仅在整份配置唯一无歧义时迁移旧组合键密钥，否则以 unclaimed| 前缀隔离保留未认领旧密钥并于提交后同步 preservedSecrets 至所有同键端点持钥或移除；capture.OpenStore 与 summary.OpenStore 返回只读句柄并在写方法返回 ErrReadOnly；summary.Store 使用同类 OS 独占锁串行化跨实例读-改-写、持久化目录级 .gen 代次防线并严格校验行 JSON，配合 Store.upsertGuarded 在提交重命名瞬间持 Generator.mu 复核取消与 cfgSeq 以及 CoveredUntil 确保切换模型、清空防回写与同窗增量更新。
- 脱敏与摘要还原遵循先结构化后还原与实例隔离：redact.Masker 保留进程级 salt 以维持占位符稳定，但反查表随实例隔离并限制容量，禁用实例不做还原；summary.Generator 为每个时间窗独立实例化 Masker，先完成 JSON 解析再按字段还原明文。
- Frame 持有内部互斥锁和公开 Close 释放方法，darwin 原生符号加载使用互斥锁与就绪标志替代 panic 后永久失效的 sync.Once；Vision 请求通过 VNRequest.cancel 配合有界宽限等待响应超时与关闭取消，Runner 通过跨启停共享 ocrPermit 保证旧队列因原生调用未响应 cancellation 提前返回时新队列也不会开启重叠 OCR 识别，并可在阻塞等待许可期间继续响应新队列停止信号。
- OCR 使用原分辨率帧，持久化 JPEG 独立缩放和压缩。识别不依赖磁盘缩略图，存储降质不降低已入队帧的识别质量。有界识别队列在关闭后拒绝新入队且不写回已停止任务结果。
- 切换存储根目录失败时中止开会话并保留错误，决不降级写入旧目录；Runner.runGen 阻止旧启停周期的慢维护错误覆盖新状态。JSONL 按天追加，JPEG 通过路径引用，Storage 记录扫描状态、扣减钳制与不可收缩跳过表，防止未扫描前绕过配额及降质死循环。
- Agent 使用无密钥、无写入路径的 query 按需读取。入口在窗口创建前分流，不启动记录器、模型服务或 CLI 凭据扫描，查询缺失目录也不创建它。
- 技能只安装说明，记录留在数据目录。应用停止生成静态技能数据，避免安装位置与记录同步耦合。旧导出通过固定内容标记识别删除，仅当发现旧文件时才清理非软链接的空目录。
- e2e 的许可检查同时覆盖 Screen（含 FrontWindow）、LiveFront 与公开授权入口，环境值严格等于 1 才放行。live 启动器将子进程 stderr 持久化到隔离目录内的 stderr.log（失败时有界读取尾部诊断），避免启动器退出后触发 SIGPIPE，并强制 RPC 超时与强杀子进程回收。
- 小票呈现摘要；简体中文与英文共享类型化消息目录，界面错误保留原始 error 对象并在渲染时按当前语言格式化。
- 键鼠计数读取系统累计计数器。不注册输入监听，也不需要权限。默认关闭，关闭时不读数。密码框里的按键、敏感应用、休眠、锁屏、暂停与计数器回绕时作废或屏蔽增量。只有开关覆盖整个快照或会话区间时才写计数。零值照写，缺失表示未计数。配置键使用 inputCounts；旧键 inputMonitor 作废。
- 应用图标画小票从出纸口吐出，色值取自小票界面。机身不加指示灯，纸上印时刻不印金额，开发版图标采用琥珀色机身与正式版区分，不使用分层 .icon 资源。
